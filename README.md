# 淘宝抢购助手

原生 Android 应用，支持 Android 12 及以上。它保存一个淘宝商品的链接、SKU 文字和开售时间，到点后通过无障碍服务打开已登录的淘宝，自动提交一件商品，并停在待支付页面。

本应用不保存淘宝账号密码，不处理验证码或风控验证，也不会点击支付按钮。请遵守淘宝平台规则，仅用于个人购买。

## 安装

1. 安装 `dist/taobao-assistant-debug.apk`，允许该来源安装应用。
2. 打开“抢购助手”，依次开启：
   - 无障碍服务：系统设置 → 无障碍 → 已下载的应用 → 抢购助手。
   - 精确闹钟：系统设置 → 应用 → 特殊应用权限 → 闹钟和提醒 → 抢购助手。
   - 通知：系统设置 → 应用 → 抢购助手 → 通知。
3. 在小米 / 红米上继续设置：
   - 应用设置 → 授权管理 → 自启动：允许。
   - 应用设置 → 权限管理 → 后台弹出界面：允许。
   - 应用设置 → 省电策略：无限制或不受限制。
   - 最近任务中锁定“抢购助手”，减少系统清理后台的概率。

不同 HyperOS 版本的菜单名称可能略有不同。应用内的“小米 / 红米设置”卡片提供相关系统设置入口。

## 使用

1. 粘贴淘宝或天猫商品链接，也支持 `m.tb.cn`、`e.tb.cn` 分享链接。
2. 填写商品页面中可直接看到的 SKU 文字。多个规格用 `/` 分隔，例如 `黑色 / 256GB`；应用会按顺序精确点击各规格，再点击确认。
3. 选择未来的开售时间。
4. 勾选自动提交确认，然后保存。
5. 开售前 2 分钟应用会通知解锁手机。到开售前 15 秒，应用打开淘宝；开售时间到达后开始操作。
6. 成功时停在待支付页面，付款由本人完成。

手机必须已解锁、屏幕点亮、网络可用、淘宝已登录。应用无法绕过锁屏、验证码、风控或登录页面；遇到这些情况会停止并通知。第一版只保留一个预约任务，同一时间只购买一个商品的一件。

## 构建

要求 JDK 17+、Android SDK Platform 35 和 Build Tools 35.0.0：

```bash
./gradlew testDebugUnitTest assembleDebug
```

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。

## 已知限制

- 淘宝界面、按钮文字和控件结构变化后，状态机可能需要更新；应用不会退回坐标盲点。
- 结算页必须能明确识别数量为 1，否则会停止，不会提交。
- 金额不做校验，这是产品确认时选择的行为。
- 精确闹钟、后台启动和无障碍服务仍可能被厂商系统限制；需完成上述小米设置。
- 无法在电脑端完成真实淘宝页面兼容性验收。首次使用应先用低风险商品做一次人工监督测试。
